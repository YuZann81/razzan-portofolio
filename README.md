# Razzan Gianni Portfolio

Personal portfolio website built with Next.js, TypeScript, Tailwind CSS, and deployed on Vercel.

## Overview

This portfolio is designed to showcase selected projects, technical skills, development process, and contact information.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Vercel
- GitHub

## Sections

- Hero
- Works
- Approach
- Services
- About
- Contact
- Footer

## Design Direction

The interface follows a minimalist engineering-inspired design system with:

- Black and white visual foundation
- Electric blue accent color
- Geist and Geist Mono typography
- Grid-based layout
- Clear spacing and borders
- Minimal decoration

## Development Workflow

This project uses a pull request based workflow:

1. Create a new branch
2. Make changes
3. Commit changes
4. Push the branch
5. Open a pull request
6. Merge into main
7. Vercel deploys automatically
